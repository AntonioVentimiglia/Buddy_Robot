# Figures

Every figure in Buddy is generated by a script here and written to
`assets/figures/`. `python3 tools/build.py` runs all of them (it globs
`plot_*.py`), so a parameter change propagates to the pictures in the same pass
that regenerates the URDF, the firmware header and the analysis documents. A
figure that cannot be regenerated from committed code does not go in a report.

## Two families, one palette

| | Quantitative figures | Integration diagrams |
|---|---|---|
| **Scripts** | `plot_drive_fbd`, `plot_power_budget`, `plot_torque_envelope` | `plot_ros_graph`, `plot_control_safety_loop`, `plot_power_one_line`, `plot_interconnect`, `plot_fault_state_machine`, `plot_startup_sequence` |
| **Renderer** | matplotlib | [`blockdiagram.py`](blockdiagram.py) — dependency-free SVG |
| **Data from** | `buddy_calcs` (design params + requirements) | `docs/system_model/integration_map.yaml`, `pin_map.md`, the bridge's own `BaseParams` |

Matplotlib draws Buddy's charts well and its block diagrams badly, hence the
second renderer. Both families import [`palette.py`](palette.py) — one definition
of every colour in the project, assigned by the job it does (blue = command flow,
green = power, red = safety, purple = future hardware) and never by series index.

## Layout is checked, not eyeballed

`Canvas.save()` calls `Canvas.audit()` first: every component box, label and edge
tag is bounds-checked against the canvas and against every other element, and a
collision **fails the build**. This exists because a hand-placed label degrades
the moment a parameter change makes it longer — the point of a parametric build
is that you don't have to re-inspect nine figures after editing one number.

The estimate is intentionally conservative (constant-ratio text metrics, so the
output stays identical on any host). It was cross-checked once against real
browser font metrics — 417 text elements across the six integration figures,
zero collisions.

## Adding a figure

1. Write `plot_<name>.py` here; read your data from `buddy_calcs`, never retype it.
2. Write to `assets/figures/<name>.svg`; print the path you wrote.
3. `python3 tools/build.py` picks it up automatically.
4. Cite it from a milestone report (`figures:` frontmatter) so it reaches the site.
